# Planting Scheduler

## Context

* **Origin** Developed as part of the second C# course at Malmö University.
* **Objective** This desktop application visualizes planting schedules based on garden-, and vegetable profiles.
* **Status** 🟢 Complete/Functional

---

## Systems Architechture

* **Logic** OOP + MVC inspired architechture with WPF XAML frontend.
* **Tech Stack** C# + XAML

---

## Functionality

* Add garden profiles (Zone, minTemp, maxTemp...)
* Add plant profiles (minTemp, maxTemp, timeToHarvest...)
* Add plants to gardens
* Generate visual planting schedules in a Gantt-chart style

---

## Setup & Usage

1. Clone the repository
2. Open in IDE of your choice
3. Add gardens and plants
4. Generate your own planting schedules!
